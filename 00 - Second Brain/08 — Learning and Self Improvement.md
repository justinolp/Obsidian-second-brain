# Learning and Self Improvement

## Purpose
The Second Brain improves both its own architecture and the quality of work performed through it.

## Learning loop

`Outcome → Evidence → Failure/Success Pattern → Learning → Candidate Improvement → QA → Canonical Rule/Skill → Regression → Reuse`

## Capture
Record:
- what happened;
- what was expected;
- what differed;
- root cause;
- impact;
- corrective action;
- reusable lesson;
- whether a rule, workflow, skill or dependency should change.

## Promotion gates

A learning becomes a system rule only after sufficient evidence and regression validation. A single anecdote should normally remain a candidate learning.

## Self-improvement domains

- retrieval quality;
- reasoning quality;
- orchestration;
- tool/connector selection;
- workflow design;
- QA coverage;
- persistence quality;
- error recovery;
- skill lifecycle;
- system simplicity and maintainability.
