# Authority Model

## Rule
Each type of truth has one primary authority. Cross-system copies are references or operational projections, never competing authorities.

### Obsidian — Knowledge/System Authority
Canonical system rules, architecture, invariants, workflows, skills, research, concepts, decisions, learnings, errors/improvements and project knowledge references.

### Trello — Task/Control Plane
Tasks, operational status, execution queues, planning and control state.

### GitHub — Code Authority
Runtime, adapters, integrations, source code, releases and technical version history.

### ChatGPT — Reasoning / Interface
Conversation, interpretation, synthesis, reasoning and interaction layer.

### Runtime — Orchestration / Integration
On-demand execution, capability routing, adapters and enforcement.

## Conflict resolution

1. Identify the domain.
2. Consult that domain's authority.
3. Record contradictions rather than silently merging them.
4. Verify.
5. Canonicalize the resolved state.
6. Update dependent projections.
