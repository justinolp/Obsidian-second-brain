# Retrieval System

## Goal
Find the smallest sufficient set of trusted knowledge needed for the current task.

## Retrieval order

1. Current request and explicit constraints.
2. Relevant canonical Obsidian notes.
3. Project Hub / MOC / index.
4. Linked decisions, research and learnings.
5. Trello operational state when execution is involved.
6. GitHub implementation state when code/integration is involved.
7. External research when required.

## Obsidian retrieval tools

Combine:
- Search
- Properties
- Backlinks
- Outgoing Links
- MOCs / index notes
- Bases for structured views

## Retrieval rules

- Prefer canonical notes over duplicated summaries.
- Follow links when context is missing.
- Do not load the entire vault unless the task explicitly requires global analysis.
- Record uncertainty when retrieval is incomplete.
- Distinguish historical information from current canonical state.
