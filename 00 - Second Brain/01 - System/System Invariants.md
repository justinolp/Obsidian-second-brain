# System Invariants

These are protected constraints of Second Brain V1.

1. **Obsidian remains Knowledge/System Authority.**
2. **Trello remains the operational Task/Control/Planner plane.** It is not a second knowledge authority.
3. **GitHub remains the code/version/history boundary.** Repository state is not automatically Android state.
4. **Runtime is the mandatory execution-oversight and evidence gate** for every relevant `SECOND_BRAIN_FULL_PASS`.
5. **ChatGPT is the reasoning/interface layer** and cannot self-issue a Runtime PASS or COMPLETED state.
6. **V1 remains on-demand.** No 24/7 daemon is required.
7. **The historical path `Second brain/SECOND_BRAIN_V1_Obsidian/SECOND_BRAIN` is not an active runtime, sync, URI, QA or completion target.**
8. **Retrieval precedes invention** when relevant canonical knowledge exists.
9. **Authority conflicts are resolved explicitly; they are not silently blended.**
10. **Truth states remain distinct:** `INTENDED → ATTEMPTED → SUCCEEDED → VERIFIED → PERSISTED`; later contradiction is `REGRESSED`.
11. **A plan, claim, URI, API success, commit or sync acknowledgement is not execution/destination proof by itself.**
12. **Canonical persistence requires actual write + read-back + integrity verification.**
13. **Runtime mandatory-gate failure is fail-closed:** missing or contradictory evidence means `BLOCKED`, `UNVERIFIED`, `FAIL` or `REGRESSED`, never silent success.
14. **TASK LANE and SYSTEM LANE must both satisfy their applicable gates before merge.**
15. **No evidence deletion, stale-state overwrite or alternate-tool route may bypass governance.**
16. **SuperSync is transport; Advanced URI/local adapters are actuation boundaries; neither becomes Knowledge Authority.**
17. **External research is evidence, not system authority, and must carry provenance when materially used.**
18. **Repeated failures are converted into explicit learning, rules, skills, checks or regression tests only after verification.**

## Completion

`COMPLETED` is allowed only when the applicable success contract is satisfied, both lanes are verified, required persistence/read-back checks pass, regression/trace requirements are satisfied and the Runtime returns `PASS`.
