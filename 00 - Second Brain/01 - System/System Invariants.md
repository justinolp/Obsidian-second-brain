# System Invariants

These are protected constraints of Second Brain V1.

1. Obsidian remains Knowledge/System Authority.
2. Trello remains operational Task/Control/Planner plane.
3. GitHub remains Code/Versioning Authority.
4. ChatGPT remains Reasoning/Interface layer.
5. Runtime is on-demand; V1 is not a 24/7 system.
6. No public HTTP listener is required; local process/stdio is preferred for the Obsidian bridge.
7. Retrieval precedes invention when relevant knowledge exists.
8. Canonical system truth requires verification and regression evidence.
9. Atomic notes are preferred over duplicated knowledge.
10. Completion requires Task Lane + System Lane to pass and merge.
