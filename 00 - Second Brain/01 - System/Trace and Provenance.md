# Trace and Provenance

Every durable knowledge item should answer:

- What is this?
- Where did it come from?
- When was it created/updated?
- Who/what produced it?
- What evidence supports it?
- What verification level does it have?
- What notes, decisions or projects depend on it?

## Provenance classes
- conversation
- Trello
- GitHub
- research/web
- direct observation
- system execution

## Rule
Provenance describes origin; verification describes trust. They are separate fields.
