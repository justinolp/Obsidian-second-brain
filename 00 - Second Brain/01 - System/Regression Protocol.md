# Regression Protocol

Changes affecting system truth require regression review.

## Check
1. Does the change preserve authority boundaries?
2. Does it preserve the Full Pass?
3. Does it preserve Task/System Lane separation?
4. Does it preserve retrieval-before-invention?
5. Does it preserve persistence and read-back requirements?
6. Does it introduce contradictory rules?
7. Does it change integration assumptions?
8. Is the new state documented and linked?

## Promotion
Candidate → reviewed → verified → canonical only when evidence supports the promotion.
