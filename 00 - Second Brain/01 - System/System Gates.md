# System Gates

## Execution Gate
A relevant task activates the Second Brain Full Pass.

## Authority Gate
Identify the correct authority before reading or writing system truth.

## Success Gate
Define a concrete Success Contract / Definition of Done before execution.

## Verification Gate
Do not promote assumptions to canonical truth without evidence.

## Persistence Gate
Important new knowledge, decisions, rules, learnings and errors must be persisted in the correct location.

## Read-back Gate
After persistence, read back the stored result when the integration supports it.

## Regression Gate
Changes to rules, workflows or integrations must be checked for regressions.

## Completion Gate
Only merge Task Lane and System Lane after required steps and evidence are complete.
