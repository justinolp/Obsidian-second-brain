# MOC — Knowledge

**Purpose:** Navigate durable knowledge without becoming a second authority.

## Types
- Concepts
- Topics
- Technical knowledge
- References
- Research findings
- Decisions and consequences
- Learnings

## Retrieval
Use Search + Properties + Backlinks + Outgoing Links. Prefer atomic notes and explicit semantic relationships.

## Lifecycle
Candidate → Atomic → Classified → Linked → Verified → Canonical → Used → Learned → Revised/Deprecated
