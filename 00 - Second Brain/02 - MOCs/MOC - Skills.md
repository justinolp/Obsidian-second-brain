# MOC — Skills

Skills are executable capabilities and procedures, not general knowledge.

## Lifecycle
Candidate → Tested → Verified → Active → Improved → Deprecated

## Skill quality
A skill should define trigger, prerequisites, inputs, procedure, success contract, failure handling, verification and related workflows.
