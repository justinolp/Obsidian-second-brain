## Layer model

**Interface → Orchestration → Control → Knowledge → Execution → Verification → Learning**

### System authorities

| Domain | Authority |
|---|---|
| Knowledge / system truth | Obsidian |
| Tasks / operational state | Trello |
| Code / versioning | GitHub |
| Reasoning / user interface | ChatGPT |
| Integration / orchestration | Runtime |

## Design principles

1. One canonical source per kind of truth.
2. Atomic notes, explicit relationships, minimal duplication.
3. Retrieval before invention.
4. Every important change has provenance and verification state.
5. Execution and knowledge are separate but linked.
6. Learning feeds back into rules, skills, workflows and QA.
7. Never promote an assumption to system truth without verification.
8. V1 remains on-demand; no 24/7 runtime is required.
